# 自动化任务执行记录：PastDrift 小说续写

## 任务模式（固定流程）
1. 读 `SETUP.md` + `outline.md`（outline 很大，需用 offset/limit 或 Grep 定位最新章节，勿整文件读）
2. `ls chapters/` + `git log -5` 确认最新章节文件与进度
3. 检查最新章是否满 10 节：未满则追加下一节；满 10 节则新建 `第N章.md`
4. 每节约 800 字，追加到对应章节文件
5. 更新 `outline.md`：分节列表打勾、字数、新增伏笔、下一节方向
6. `git add -A && git commit && git push`（远程：github.com:xingjiahe/PastDrift.git，分支 main）

## 关键约定
- 同一章内容只写在同一章节文件中
- outline.md 文末会持续追加最新章的分节与伏笔，最新章信息在文件尾部而非按序号中段（章节顺序有错位，如第八章在第十章之后）
- 章节文件头部含「状态/字数/时间线」，需同步更新
